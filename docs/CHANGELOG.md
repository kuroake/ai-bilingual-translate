# 更新日志

## 1.1.0

### 新增

- **动态注入**：扩展安装或重新加载之前就已打开的标签页，点图标或按快捷键时自动注入内容脚本，不再要求用户手动刷新页面（新增 src/shared/inject.js，content 各模块入口加了幂等守卫）。
- **译文配色自适应宿主背景**：系统主题与网页主题不一致时（系统亮色 + 深色网页，或反之），译文自动切换浅色 / 深色文字与批注线。深色宿主背景下的对比度从 2.52:1 提升到 12.38:1。
- 工具栏图标点击行为可在设置中切换：默认「打开控制面板」（不占用图标），也可选择「直接翻译 / 还原」。

### 改进

- 右键菜单从 3 项精简为 2 项：「AI 翻译选中文字」、「AI 双语翻译 / 还原此页面」。
- 设置版本升级到 2，读取旧版设置时自动迁移，避免早期默认值残留（例如工具栏图标曾被设为直接翻译）。
- README 增加效果截图与「没有 API Key 也能先看效果」说明。

### 修复

- 修复扩展安装/重载后，已打开页面里 popup 显示「页面脚本未响应」、必须手动刷新才能翻译的问题。
- 修复打包脚本在 Windows PowerShell 5.1 下丢失版本号、中文输出乱码的问题（改为 UTF-8 BOM + .NET 显式 UTF-8 读取）。

### 测试与工具

- 新增 extension/scripts/mock-server.mjs：本地 OpenAI 兼容 mock 服务（流式 / 非流式 / 401 / 模型列表），可无 Key 验证全链路。
- 新增 extension/scripts/e2e.mjs：headless Edge 加载真实扩展 + mock LLM，端到端验证全页翻译、截图与宿主背景配色断言。
- 新增 extension/scripts/e2e-inject.mjs：模拟「安装前已打开的标签页」，验证动态注入与幂等。
- 单元测试 139 项、静态检查 57 项、UI 双视口双主题 20 组截图全部通过。
